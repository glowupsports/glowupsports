## Rule
The adult Glow rating engine (`server/services/glow-rank-engine-adult.ts`) uses UTR-style scoring:
- `scoreRatio = games_won / total_games` (not binary 0/1)
- `delta = K * (scoreRatio - expectedScore) * marginFactor * trustFactor`
- A close loss against a much stronger player can still yield positive MMR
- Falls back to binary outcome + `calculateMarginFactor(gamesDiff)` when no set score is provided

**Why:** UTR approach rewards competitive performance, not just wins. Players who fight hard in losses gain or lose less.

**How to apply:**
- Send `scoreJson: [{p, o}]` (per-set games) in the POST /match body
- The server also accepts `setScore` text ("6-4, 6-3") as a fallback parse
- Never use `gamesDiff` alone for MMR calculation; prefer `scoreJson`

## Skill Gates
- Skill gates are NO LONGER promotion blockers (since this task)
- `canPromote()` only checks MMR threshold — MMR is the sole gate
- Skill gates returned as `achievementBadges` in /match response and `achievementBadges` in /full-profile
- `getSkillGateAchievements()` returns which gates the player has unlocked

## Score Required + Consistency Guard
- Both POST /match and POST /doubles-match **require** `scoreJson` (400 if absent/empty)
- Server checks: if sets won by each side are unequal, declared `didWin`/`team1Won` must match — returns 400 "Score/result mismatch" otherwise
- Client mirrors this check before submitting; "Score" section label is no longer marked Optional
- `parsedScoreJsonRaw` is the canonical validated variable in both route handlers

## Doubles
- `updateDoublesRatings()` accepts `scoreJson` (player1's perspective) — now required
- The route mirrors scoreJson for team2 (flip p/o) so each team sees their own ratio
- Doubles results are now persisted to `adult_glow_matches` (4 rows per match, one per player)
- Before this task, doubles matches were NOT saved to the DB

## Explanation Format
Dutch language: `"+18 rating — Dominante overwinning (6-1, 6-2) vs gelijkwaardige tegenstander"`
Generated by `generateMatchExplanation(delta, scoreRatio, didWin, opponentMmrDiff, scoreJson)`
